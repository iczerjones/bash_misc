A spot to drop scripts I might need in the future or those I want to collaborate on

- **sarollup.sh** - Forensic 'snapshot' of chronologically compiled (sysstat) **sar** logs, dmi system info, SMART logs, etc so get a picture of a system and it's recent behavior
- **display_temps/displaytemp.sh** - Categorize, display and log (to csv) temperatures for Intel hybrid core CPUs, disks, etc. Used for monitoring highwater, average, and momentary temps in time series
